\begin{abstract}
This report documents the current evidence for the GBT+JEPA trading architecture.  The strict out-of-sample benchmark trains through March 31, 2026 and tests April 1 through May 29, 2026.  In that benchmark, the combined \texttt{base\_jepa} 180 minute direction model outperforms both the base GBT and JEPA-only models.  The fixed $\Delta=0.70$ 0DTE option execution rule is currently stronger than the learned OptionValueJEPA strike/exit alternatives on the practical promotion criteria.  Production-history diagnostics are reported separately and are explicitly not out-of-sample evidence.
\end{abstract}

\section{Executive Conclusion}

The promoted production candidate is:

\begin{center}
\textbf{GBT+JEPA 180 minute direction model + fixed $\Delta \approx 0.70$ 0DTE option execution.}
\end{center}

The main reasons are:

\begin{enumerate}
  \item \texttt{base\_jepa} improves strict OOS direction-trade performance relative to the base GBT.
  \item JEPA-only is weaker than base+JEPA, so JEPA should be used as a feature generator, not as a standalone replacement.
  \item Fixed $\Delta=0.70$ option execution beats learned strike selectors on the most stable OOS option-policy comparison.
  \item Learned 5 minute exits do not yet capture the large oracle-exit ceiling.
  \item Production final diagnostics are strong but must be treated as model-history checks, not validation.
\end{enumerate}

\section{Evaluation Definitions}

\subsection{Prediction Metrics}

For the 180 minute direction model:

\[
  y_t = \mathbb{1}[S_{t+180m} > S_t].
\]

Reported prediction metrics include:

\begin{itemize}
  \item AUC,
  \item accuracy,
  \item balanced accuracy,
  \item Spearman correlation between predicted probability and future return,
  \item top-quintile and bottom-quintile future returns.
\end{itemize}

\subsection{Trade Metrics}

For proxy backtests:

\[
  \mathrm{gross\ bps}_t =
  d_t \cdot 10{,}000\left(\frac{S_{t+180m}}{S_t}-1\right),
\]

where $d_t=+1$ for long and $d_t=-1$ for short.  Net bps subtracts cost:

\[
  \mathrm{net\ bps}_t = \mathrm{gross\ bps}_t - \mathrm{cost\ bps}.
\]

PnL is:

\[
  \mathrm{PnL}_t =
  \frac{\mathrm{net\ bps}_t}{10{,}000}
  \times \mathrm{notional}.
\]

Profit factor is:

\[
  \mathrm{PF} =
  \frac{\sum_{\mathrm{PnL}>0}\mathrm{PnL}}
       {|\sum_{\mathrm{PnL}<0}\mathrm{PnL}|}.
\]

\section{Strict OOS 180 Minute Direction Test}

\subsection{Protocol}

\begin{itemize}
  \item Training cutoff: March 31, 2026.
  \item Test period: April 1, 2026 through May 29, 2026.
  \item Tickers: SPX, QQQ, SPY.
  \item Label: exact 180 minute future direction.
  \item Hold: fixed 180 minutes.
  \item Cooldown: 180 minutes.
  \item Cost: 1 bps.
  \item Notional: \$100,000 per proxy trade.
\end{itemize}

This is the key validation split because all training and threshold selection are frozen before the OOS period.

\section{0DTE Option Policy OOS Test}

\subsection{Protocol}

The option-policy OOS benchmark uses the frozen-March \texttt{base\_jepa} model as the entry generator.  For every accepted signal, the simulator constructs option candidates for delta buckets:

\[
  \Delta \in \{0.10,0.20,0.30,0.40,0.50,0.60,0.70\}.
\]

The option side is call for long and put for short.  Entry premium is spread-adjusted.  Contract count is computed from risk capital.  Exits use hard stop and take-profit unless an experiment explicitly evaluates learned exit or oracle exit.

\section{Interpretation}

The results do not say that the system is solved.  They say that the next production release should use \texttt{base\_jepa} for 180 minute direction and fixed $\Delta=0.70$ for 0DTE execution.  The evidence is strongest for the direction layer and weaker for learned option optimization.  The research gap is now clear: close the gap between fixed delta and oracle selection without sacrificing OOS profit factor.

\section{Recommended Next Tests}

\begin{enumerate}
  \item Extend the strict OOS protocol with future months as they become available.
  \item Run per-ticker slippage and spread sensitivity for the fixed-delta option policy.
  \item Train OptionValueJEPA with ticker-specific calibration or separate heads.
  \item Test rank-based losses for option candidate selection, not only regression to clipped return-on-risk.
  \item Keep learned exits behind a promotion gate requiring PF, PnL, and drawdown improvement over fixed hold.
\end{enumerate}

\section{Conclusion}

The current empirical evidence supports a conservative deployment path.  JEPA improves the GBT as a latent feature generator.  The fixed-delta option layer remains better than learned option selection.  Production diagnostics are strong but must not be confused with OOS proof.  The next research objective is to make OptionValueJEPA beat the fixed $\Delta=0.70$ baseline robustly, not merely approach oracle performance in isolated diagnostics.
