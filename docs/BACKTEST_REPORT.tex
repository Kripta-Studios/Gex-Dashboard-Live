\section{Why This Replaced Prior Packages}

The previous backfill19 SPY package and level-stability/structural-profile stack were useful stepping stones, but the current static-union package is the deployed artifact because it passes live-ready validation, starts under the current systemd units, and has a clear runtime exit contract:

\begin{lstlisting}
stop=-60%/tp=1000%/trail=50%/25%/min_hold=30m/max_hold=180m
\end{lstlisting}

The forced d50 behavior observed in earlier live tests is not the current policy target. The active service units point to the frozen2025 static-union package.

\section{Production Caveats}

\begin{itemize}
  \item Validation is only meaningful if the live feed generates the same feature surface used by the package.
  \item The validation gate is 12 trades per month because SPY does not satisfy 18 trades per month.
  \item Daily live fills and paper intents are separate evidence and must be audited after deployment.
  \item A strong backtest does not authorize features that depend on future prices, future option highs/lows, realized PnL, or labels.
\end{itemize}

\section{Live Comparison Protocol}

For each live day:

\begin{enumerate}
  \item Export \path{rt_data/YYYYMMDD/} and \path{trades_jepa/}.
  \item Parse \path{paper_order_intents_jepa.jsonl}.
  \item Compare selected candidates, entry times, deltas, contracts, exits, and hold times against a replay using the same policy.
  \item Run \path{audit_live_feature_drift.py} after the feed writes \path{event_option_snapshots_latest.parquet}.
\end{enumerate}

\section{Promotion Rule}

A future package should replace this one only if it improves the relevant live-ready evidence:

\begin{itemize}
  \item profit factor and win rate above gate;
  \item completed-month volume by ticker;
  \item causal selection with no same-month or future-month leakage;
  \item live feature equivalence;
  \item successful systemd startup and smoke test;
  \item forward live/paper behavior that matches replay.
\end{itemize}
