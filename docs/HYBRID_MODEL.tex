\section{JEPA Research Line}

The JEPA research line produced several useful artifacts:

\begin{itemize}
  \item 180 minute direction models;
  \item XInputJEPA latent features;
  \item SIGReg/VISReg-inspired anti-collapse experiments;
  \item OptionValueJEPA strike and exit research;
  \item event-option dense candidate selection.
\end{itemize}

The production winner is not a literal end-to-end JEPA controller. It is a static-union event-option policy with live-ready component registry and mechanical exits.

\section{Why Legacy Models Are Not Live}

\begin{itemize}
  \item GBT+RL underperformed stronger baselines in prior tests.
  \item OptionValue and learned exits have not beaten the simpler static policy under live-ready gates.
  \item 180 minute JEPA direction work is useful but not the currently deployed event-option policy.
  \item The live services now explicitly disable level-signal, structural-profile, and option-value paths.
\end{itemize}

\section{Promotion Standard}

A legacy model can become live only if it:

\begin{enumerate}
  \item beats the current static-union package on causal validation;
  \item passes feature leakage and live equivalence checks;
  \item exports a production package with `production\_live\_ready` status;
  \item is wired into systemd and starts cleanly;
  \item produces forward paper/live behavior consistent with replay.
\end{enumerate}
