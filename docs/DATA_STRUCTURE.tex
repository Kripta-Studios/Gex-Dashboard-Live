\section{JSONL Intent Shape}

Each paper intent records the action, ticker, contract, quantity, price, policy id, and reason. Typical actions:

\begin{lstlisting}
BUY_TO_OPEN
SELL_TO_CLOSE
\end{lstlisting}

Typical close reasons:

\begin{lstlisting}
event_option_stop_loss_30%
event_option_take_profit_50%
event_option_trail_stop
event_option_max_hold
event_option_eod
\end{lstlisting}

Reason strings can include legacy percentages from older live sessions. The current deployed exit contract is checked from the service startup log and policy, not from stale historical intent files.

\section{Logs and Exports}

\end{lstlisting}
