# EXTERNAL_OPRA_SOURCE_INTAKE — cierre sin ejecución

**Fecha:** 2026-07-26  
**Estado:** `CLOSED_NO_EXECUTION_BY_USER`

El usuario ordena abandonar NBBO/OPRA externo porque la suscripción disponible
no da acceso a esa fuente. La predeclaración y el código de admisión se
conservan como evidencia, pero quedan inertes:

- no existe `MASSIVE_API_KEY`;
- no se llamó ningún endpoint Massive;
- no se compró ni amplió una suscripción;
- no se creó capture root, shadow, seal, feature o outcome;
- no se ejecutará el capturador, builder ni auditor;
- no se reutilizará la predeclaración como V8.

Este cierre no convierte la dependencia externa en evidencia económica ni
autoriza fingir tape/NBBO con ThetaData Standard. La investigación vuelve a los
parquets `executable_quote` existentes bajo un contrato development-only
separado.
